# Held-out requests

`requests.jsonl` holds 20 requests across five domains. They were written by the team using
personas, so each `author` field starts with `team-written persona:`. S-04 and master plan §8 E3
require requests written by people outside the team; these do not meet that bar and must not be
reported as outsider requests.

Before E3 counts, replace or extend this set with requests from named outsiders who consent to
publication (for example replies to the "your rule, live" post), and record each author's consent.
